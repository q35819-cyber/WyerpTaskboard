# WyerpTaskboard Chat Wake 浏览器观察与协作桥

仅用于用户已登录且已授权的普通ChatGPT页面。浏览器扩展负责版本握手、页面状态识别、心跳、最小候选/异常引用与执行上下文协作；它不是独立任务执行者。

**改变GPT页面/会话状态只能由受控MCP执行器完成。** 扩展不得直接点击、输入、发送、导航、停止生成或刷新；不得自动调用 `chrome.runtime.reload()` 升级自己。版本过期应明确告警并等待安全的人工处理。

手动模式逐次审批、无人值守授权、人工接管及刷新最后手段规则只维护于 [全局哨兵计划](../../docs/plans/全局状态哨兵与人工接管开发计划.md)。路由恢复意图或持有候选不等于获准执行动作。

只提取状态识别所需的最小信息，不收集Cookie，不持久化/上传完整聊天正文、项目源码、文档或测试报告；不得覆盖用户未发送输入。候选只携带项目/任务/detection/角色等必要引用，执行AI回到项目读取原文。

源码版本来自 `manifest.json`，服务期望版本来自 `config/chat-browser-wake.json`；浏览器实际加载版本需要运行态核验。Token、短租约、epoch与ACK用于受控通信、去重和审计，不能替代任务claim、授权或独立性检查。配置启用、曾经ACK和当前现场可用必须分别记录。
