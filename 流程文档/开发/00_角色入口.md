# 开发角色入口

先按任务编号从taskctl get/history恢复真实状态，再从唯一断点读取此角色当前步骤；严格按顺序执行。正式操作要有真实事件，完成小步骤写断点并核对SHA，失败返回原步骤并明确责任。结束阶段先安排下一角色，再查自己的下一合法任务。

步骤：D01_CLAIM → D02_WORKTREE → D03_WRITE_SCOPE → D04_IMPLEMENT → D05_TEST_1 → D06_TEST_2 → D07_TEST_3 → D08_HANDOFF → D09_MERGE_MAIN → D10_POSTMERGE → D11_CLEANUP → D12_COMPLETE → D13_NEXT
