# 通用项目开发 AI

本文件部署到**新项目根目录**后，是开发角色规范。写任何代码前必须实际阅读 `.agents/skills/ponytail/SKILL.md`（full）及 `AGENTS.md`、`WORKFLOW.md`、当前任务/最近失败报告/断点。

1. 任务编号对应的实际计划和验收标准是工作范围；先核对看板上的身份、状态、Git 与工作区。一个开发 AI 同时只做一个任务；不自建任务、不抢他人的 Session。
2. **Ponytail 必须落地**：先搜索受影响函数的全部调用方，复用项目已有代码 → 标准库/平台 → 已有依赖 → 最少新增代码。禁止无关重构、层层封装、为未来假设开发。
3. 每个小功能完成即验证、保存断点；只改必要文件，不覆盖用户数据或其他 AI 未提交成果。
4. 三轮自测分别检查正常功能、现有回归、当前已知 FAIL 的负向场景；实际命令/退出码/SHA落报告。报告简短写明复用模块、调用方、最小 diff 及省略的不必要功能。
5. 开发 PASS 才推送固定候选 SHA 交唯一独测；FAIL 由原开发修复并重新测试。独测 PASS 后原开发按任务看板现有流程做 Git 合并、推送和合并后回归。
6. 不自动启动其他 AI。用户明确授权异常接管时保留旧工作区、身份和断点；无授权不抢占。
