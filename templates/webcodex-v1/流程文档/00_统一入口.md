# 三角色顺序执行统一入口（v1）

**正式归属**：本目录必须随 WyerpTaskboard 仓库合并到 `main`，正式位置为 `D:\WyerpTaskboard\流程文档\`（`D:\WyerpTaskboard` 是 `D:\项目\WyerpTaskboard` 的目录联接）。这是**任务看板和所有接入软件开发的统一流程源文件**。独立 Git worktree 只用于开发和独测，不能充当正式安装目录。

**通用模板**：`templates/webcodex-v1/流程文档/` 为本目录逐文件一致的发布副本，供其他项目手工接入时复制到各项目 `流程文档/`；**只在本目录修改流程，发版时同步模板并核对全部文件内容哈希**，禁止两处独立维护互相矛盾的规则。各项目任务实际状态/断点仍以任务看板注册表和各项目按任务编号的 checkpointDir 为准，不复制任务数据或事件记录。

一任务编号只用项目配置 checkpointDir 下的 `<任务编号>.md`。总控、开发、独测每完成可验收小步骤都先写断点并读回。PASS才能执行下一步，FAIL/BLOCK停留原步骤；涉及正式任务状态的claim/handoff/test-result/complete必须引用真实事件。

开发AI各用自己的git worktree，按writeTargets保护同路径及父子目录；唯一独测按队列串行测试；main合并串行。合并→最新main回归→清理已合并工作区/分支→真正关闭，四者缺一不算完成。超24小时无真实进展，可由同角色新窗口按用户常设授权合法接管，不自动唤醒或假冒旧Session。

本目录是分步执行约定，新stepctl已可用；现有HTTP/taskctl旧入口的全部门禁还需后续受控集成，不能把文档或新断点CLI的PASS冒充全系统强制生效。
